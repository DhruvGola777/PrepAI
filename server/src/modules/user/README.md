# User Module

This module handles user profile management, including personal information, resume uploads, and statistics.

## Key Files
- `user.controller.js`: Manages user profile updates and resume upload logic.
- `user.service.js`: Contains business logic for profile retrieval, updates, and resume entry management.
- `user.model.js`: Schema for user profiles and resume metadata.
- `user.routes.js`: API endpoints for user profiles and resumes.
- `user.validation.js`: Zod schemas for validating user profile updates.
