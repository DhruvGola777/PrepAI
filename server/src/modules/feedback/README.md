# Feedback Module

This module handles the storage and retrieval of interview feedback and evaluation reports.

## Key Files
- `feedback.controller.js`: Manages feedback-related API requests.
- `feedback.service.js`: Contains logic for saving and fetching feedback entries.
- `feedback.model.js`: Schema for interview feedback data.
- `feedback.routes.js`: API endpoints for feedback.
- `feedback.validation.js`: Zod schemas for validating feedback requests.
