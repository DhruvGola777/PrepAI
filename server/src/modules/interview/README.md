# Interview Module

This module manages the lifecycle of mock interview sessions, from creation to completion, including transcript storage.

## Key Files
- `interview.controller.js`: Handles requests for starting and managing interviews.
- `interview.service.js`: Contains logic for creating, updating, and querying interview sessions.
- `interview.model.js`: Schema for interview sessions and transcripts.
- `interview.routes.js`: API endpoints for interview management.
- `interview.validation.js`: Zod schemas for validating interview-related requests.
