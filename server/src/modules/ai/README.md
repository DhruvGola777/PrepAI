# AI Module

This module handles all interactions with the AI provider (Groq) for analyzing resumes, generating interview questions, evaluating answers, and producing final feedback reports.

## Key Files
- `ai.controller.js`: Handles incoming API requests for AI features.
- `ai.service.js`: Contains business logic for calling the AI provider (Groq) and interacting with models.
- `ai.model.js`: Defines the schema for AI-generated analysis results.
- `ai.routes.js`: Defines API endpoints for AI-driven functionality.
- `ai.validation.js`: Zod schemas for validating AI-related requests.
